## 🎯 Mục tiêu

Repository này xây dựng một lớp trình bày tiếng Việt gọn, hiện đại và dễ tiếp cận trên nền mã nguồn công khai của `lopp.net`. Trọng tâm không phải sao chép nguyên văn toàn bộ website, mà là tạo một **cổng định hướng tri thức** giúp độc giả Việt Nam nhanh chóng tiếp cận các nguồn chính thức về:

- ₿ Bitcoin và kiến trúc mạng phi tập trung
- 🔐 Bảo mật Bitcoin và mô hình hóa mối đe dọa
- 🗝️ Self-custody, khóa riêng và chủ quyền tài chính
- 🕵️ Quyền riêng tư và giảm bề mặt tấn công
- ⚡ Lightning Network
- 🧪 Thử nghiệm hiệu năng node và hạ tầng Bitcoin
- 🧠 Các bài phân tích kỹ thuật, phản biện và lịch sử hệ sinh thái

| Khu vực | Nội dung |
| --- | --- |
| **Giới thiệu** | Hồ sơ, vai trò và sứ mệnh công nghệ của Jameson Lopp |
| **Tài nguyên** | Bài viết, thuyết trình, phỏng vấn, dự án, Bitcoin Info, Lightning Info |
| **Bài viết gần đây** | Một số bài tiêu biểu mới nhất, tiêu đề được Việt hóa và liên kết về bài gốc |
| **Tư duy bảo mật** | Tổng hợp các nguyên tắc adversarial security thường xuất hiện trong nội dung của Lopp |
| **Nguồn gốc** | Liên kết minh bạch tới `lopp.net`, blog chính thức và upstream repository |

## 🛡️ Nguyên tắc biên tập

1. **Không mạo danh:** đây là bản Việt hóa cộng đồng, không phải website chính thức của Jameson Lopp hay Casa.

## 🧑‍💻 Phát triển cục bộ

Đây là website tĩnh. Có thể chạy bằng bất kỳ HTTP server đơn giản nào:

```bash
python -m http.server 8000
```

Sau đó mở:

```text
http://localhost:8000/
```

Không cần framework, package manager hay bước build.
